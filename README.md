# 몽실이 공부코치 (3D 공부 섬 + Gemini AI 질문 코치)

중학생이 **각자 개인적으로** 쓰는 학습 코치 웹앱입니다.
서버는 하나, AI 키는 선생님 것 하나이고, 학생은 주소만 열면 바로 씁니다(로그인·코드 없음).
학생마다 처음 접속할 때 **'내 공부 열쇠'**가 자동으로 만들어지고, 그 학생의 기록은 **서버 안의 자기 공간**에만 저장됩니다.

```
학생 A 브라우저 ─┐  (열쇠 A)         ┌─ /api/coach → Gemini (선생님 키)
학생 B 브라우저 ─┼──────────────────┤
학생 C 브라우저 ─┘  (열쇠 C)         └─ /api/data  → Upstash Redis
                                           ├ A의 공간
                                           ├ B의 공간   ← 서로 볼 수 없음
                                           └ C의 공간
```

## 폴더 구성
| 파일 | 하는 일 |
|---|---|
| `public/index.html` | 학생이 보는 웹앱 전체 (3D 공부 섬 게임 화면) |
| `public/mongsil.glb` | 힉스필드(Meshy)로 만든 걷는 3D 몽실이 |
| `api/coach.js` | AI 질문 코치·사진 읽기: 코칭 규칙, 사용량 제한, Gemini 호출 |
| `api/data.js` | 학생별 기록 저장: 열쇠마다 자기 공간에만 읽고 쓰기 |
| `dev-server.mjs` | 내 컴퓨터 미리 보기용 (배포에는 안 쓰임) |

## 배포 순서 (Vercel, 무료 등급)
1. **준비**: Google AI Studio에서 Gemini API 키 발급, vercel.com 가입.
2. **배포**: PowerShell에서 이 폴더로 이동한 뒤
   ```powershell
   npx vercel login
   npx vercel
   ```
   질문에는 `Y` → 내 계정 → `N`(새 프로젝트) → 이름(예: `mongsil-coach`) → Enter(`./`) → `N`.
3. **저장소 연결**: vercel.com → 프로젝트 → **Storage** → **Upstash for Redis**(무료) 만들기 → 이 프로젝트에 연결.
   `KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어옵니다.
4. **AI 키 넣기**: **Settings → Environment Variables**에 `GEMINI_API_KEY` 추가. 필요하면 `DAILY_LIMIT` 등도.
5. **정식 배포**:
   ```powershell
   npx vercel --prod
   ```
6. **확인**: `https://내주소/api/coach` → `{"ok":true,...}`. 사이트를 열어 퀘스트 하나를 체크한 뒤,
   위쪽 저장 표시가 **"내 공부 공간에 저장됨"**이면 성공입니다. ("이 기기에 저장됨"이면 3번 저장소 연결을 확인)
7. **학생 안내**: 주소만 알려 주세요.

## 학생에게 알려 줄 것
- 처음 들어가면 자동으로 내 공간이 생겨요. 기록은 나만 볼 수 있어요.
- **트로피 탑 → 내 공부 열쇠**를 공책에 적어 두세요. 다른 기기(집 컴퓨터 등)에서 열쇠를 넣으면 이어서 쓸 수 있어요.
- 열쇠는 비밀번호와 같아요. 친구에게 알려 주지 마세요. 잃어버리면 찾아 줄 수 없어요.
- 이름·학교·전화번호 같은 개인정보는 적지 마세요.
- 오답 사진은 찍은 기기에만 저장돼요.

## 비용과 사용량
- AI 질문과 사진 읽기는 모두 **선생님의 Gemini 키**로 처리됩니다. 무료 등급 한도를 넘으면 잠시 "친구가 너무 많아요" 안내가 나옵니다.
- 기본 제한: 기기당 하루 60번, 같은 인터넷 주소당 하루 150번, 기기당 1분 6번.
  **학교 와이파이처럼 여러 학생이 같은 주소로 쓰면 `IP_DAILY_LIMIT`을 늘려 주세요** (예: 학생 수 × 30).
- 주소가 외부에 퍼져서 모르는 사람이 쓰는 것 같으면 `CLASS_CODE`에 비밀번호를 넣고 다시 배포하세요. 그 비밀번호를 아는 사람만 AI를 쓸 수 있게 됩니다.

## 개인정보·보안
- 서버에는 열쇠 원문이 아니라 해시값만 저장되고, 학생 기록 내용은 로그에 남지 않습니다.
- 다만 저장소(Upstash) 관리자인 선생님은 기술적으로 저장된 기록을 볼 수 있습니다. 학생에게 개인정보를 적지 않도록 안내해 주세요.
- 기록은 `DATA_KEEP_DAYS`(기본 400일) 동안 접속이 없으면 자동 삭제됩니다.
- **Gemini 무료 등급은 입력 내용이 Google 서비스 개선에 쓰일 수 있습니다.** 학교 개인정보 지침을 확인하세요.
- API 키는 Vercel 설정에만 넣고 코드·채팅에는 넣지 마세요.

```powershell
Copy-Item .env.example .env

npm run dev         # http://localhost:3000
```
